ATLAS QUEST V2 — PIXEL COMIC ADVENTURE

1. Décompressez le ZIP.
2. Copiez TOUT le contenu du dossier dans la racine de votre dépôt GitHub Pages (index.html à la racine).
3. Dans GitHub, Settings > Pages > Deploy from a branch > main / root.
4. Ouvrez votre URL GitHub Pages.
